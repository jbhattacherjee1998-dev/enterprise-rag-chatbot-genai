
Enterprise RAG Chatbot - Complete Learning Notes

PROJECT GOAL
Build an Enterprise RAG Chatbot using Python, Streamlit, Ollama, Llama3, ChromaDB and LangChain.

Architecture:
PDF -> Loader -> Chunking -> Embeddings -> Vector DB -> Similarity Search -> LLM -> Answer

==================================================
PRE-REQUISITES
==================================================

1. Install VS Code
Purpose:
- Code editor
- Integrated terminal
- Python development

2. Install Python 3.11
Verify:

python -m venv venv

Activate:

==================================================
INTERVIEW QUESTIONS
==================================================

What is RAG?
Retrieval Augmented Generation combines retrieval and LLM generation.

What are embeddings?
Numerical vector representation of text.

Why chunking?
LLMs have context limits.

Why ChromaDB?
Stores vectors and supports semantic search.

Why Ollama?
Free local LLM execution.

What is similarity search?
Finding semantically relevant chunks.
